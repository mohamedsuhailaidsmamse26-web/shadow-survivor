SHADOW SURVIVOR
A new Godot 4.7 project for an original third-person open-world survival exploration prototype.
Current milestone
3D test environment and lighting
Third-person capsule placeholder player
Basic walking, running and jumping
Simple on-screen touch controls
Keyboard input can be added/configured in the next milestone
Important
This is a starter prototype, not a finished AAA game and does not yet contain realistic human models, vehicles, missions, advanced terrain, or optimized mobile graphics. Those need to be added and tested in later milestones. The capsule is only a temporary placeholder.
Open in Godot
Download and extract this repository.
In Godot Project Manager choose Import.
Select the project.godot file inside this folder.
Open the project and press Play.
